# Doomtron
A small Gameboy esque console made to play one of the greatest games ever DOOM 1993, ft a Rasperrby Pi Pico and  TFT Screen.
## <ins>Why Doom1993? (Read the TLDR if you don't want to hear me gush about doom)</ins>
DOOM 1993 is a notorious game made on the Doom engine, heralded as the first 3D game ever. The gem made by id software works by replicating 3D graphics by using several layered 2D sprites giving a 3D feel to it.In honesty it can be called a 2.5D game, the entire game is a 2D optical illusion that looks 3D!!! A wonderful piece of tech and a game that holds up pretty well now too, as the first ever FPS (EXCLUDING WOLFESNSTEIN 3D,which came first but wasn't as popular,also made by id software).Now the main wonder and awesomeness of DOOM 1993 is that it can played on anything, globally among most tech users the questions to test a device are "Can it run Crysis?" among PC users (since it was one of the most graphically and high requirement game at the time) and "Can it run DOOM?" among general device users. It can run on almost anything,and I do mean anything, although it needs to be coded in at times. It can run on,For example:Your phone,most Ti calculators,Your grandma's phone,A potato pc,a Potato (like the vegetable),An Xray machine, A heart rate monitor,etc. And to celebrate such a wonderful game,I decided to make a console tailor made for DOOM 1993,since it can run alongside anything, Why not run solo for once?
<br>
<br>
TLDR; DOOM 1993 can run on most devices, so why not make an exclusive device to run it for once.
## <ins>THE FEATURES<ins>
- Doom 1993 fully playable
- full working button system, including movement ,shooting,runnning,etc.
- usb port for power
